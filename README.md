# tonsite.beaute

Static site of tonsite.beaute: booking pages for nail and lash technicians, beauty institutes and hair salons in France.
Published with GitHub Pages: https://kamgangharold-ui.github.io/tonsite-beaute/

The HTML is generated by a build script kept outside this repository; edit the source, rebuild, then copy the output here.
No cookie, no tracker, no external script. The three pages under `demos/` are fictitious examples.

## Agent skills

`.claude/skills/` holds the skills an AI coding agent uses to build, polish, test and audit the pages (start with `web-ui-pipeline`). Third party skills keep their own LICENSE and a SOURCE.md with the origin. `robots.txt` keeps crawlers out of that folder.
